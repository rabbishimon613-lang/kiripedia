# On This Day — enrichment run log

Weekly unattended pass. Each entry records coverage before → after, every event added,
every existing event enriched, every candidate rejected and why, and what was swept so the
next run can rotate onward.

See `ON-THIS-DAY-PLAN.md` for the lanes and `ARTICLE-WORKFLOW.md` for binding doctrine
(strict `events:` rule: YYYY-MM-DD precision, date from Kiriakou's own mouth).

### The lane-3 cap is now the binding constraint

Measured this run: **621 sources land on 227 of the 260 still-empty calendar days.** Source
publication dates alone could take the calendar from 106 days to roughly 333. The routine caps
lane 3 at "a handful per run", so 5 were used, chosen for having a real topical home rather than
being filed under the biography as filler. At five a week that is about forty-five more runs.

Lanes 1 and 2 are close to dry: strict canon extraction produced **three** new days this run
against sixteen in run 1, and the prose sweep produced one. **Whether the calendar fills is now
almost entirely a question of the lane-3 cap.** Raising it — say, to thirty a run, with the same
requirement that each event hang off an article the appearance actually anchors — would fill the
calendar in two months without touching the single-source rule. That is a decision for the user.
